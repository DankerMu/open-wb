- Acceptance evidence reference:
- Decision: expand / amend-and-repeat / stop

The playbook is the fan-out prompt: write it for an engineer who has not read this
conversation, with exact commands and every error met plus its resolution. Wave workers refuse
to start without it. Report every gap a worker hits — including gaps the worker resolved
itself; a silently fixed gap is rediscovered by every later unit.
