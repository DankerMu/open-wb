"button"} class="ui-btn ui-btn--<variant> ui-btn--<size> [ui-btn--loading]" disabled={disabled || loading} aria-busy={loading || undefined}>`；`loading` 时插入 `<span class="ui-btn-spinner ui-spin" aria-hidden="true" />`，children 始终渲染且仍占位：`.ui-btn.ui-btn--loading { position: relative; color: transparent }`（特异性 (0,2,0)，**写在 button.css 最后**，压过同为 (0,2,0) 的 `[data-theme="dark"] .ui-btn--primary` 与所有 (0,1,0) 变体色），`.ui-btn-spinner { position: absolute; inset: 0; margin: auto; width/height 14px; border-top-color: transparent }`、`[data-theme="dark"] .ui-btn--primary .ui-btn-spinner { border-color: var(--wb-palette-black-90); border-top-color: transparent }`（写在末规则之前）——spinner 脱离文档流，按钮宽高与非 loading 态一致（父 spec"保留宽度"），可访问名仍来自 label 文本。button.css 中所有 `:hover` 选择器 SHALL 写成 `:hover:not(:disabled)`（loading 即 disabled，hover 色规则不再命中）。jsdom 量不了宽度：以静态断言兜底——`button.css` 中 `.ui-btn-spinner` 含 `position: absolute`；文件**最后一个**规则块的选择器为 `.ui-btn.ui-btn--loading` 且含 `color: transparent`；文件内每个含 `:hover` 的选择器都含 `:not(:disabled)`。`size="icon"` 为 32×32 方形、调用方须传 `aria-label`（测试覆盖）。CSS 映射 demo:570-586：base 高 32/padding 0 14/radius 8/13px/500；`--sm` 26/0 10/12px/radius 6；`--lg` 40/0 20/14px/radius 10；`--icon` 宽 32 padding 0；`:disabled` opacity .45；`:active:not(:disabled)` opacity .82 + translateY(.5px)。变体取色：primary 浅 `bg var(--wb-palette-black-90)`/`fg var(--wb-text-white)`、hover `black-70`，暗 `bg white-90`/`fg var(--wb-palette-black-90)`、hover `white-70`；secondary `bg-secondary`/`text-primary`、hover `bg-hover`；ghost 透明/`text-secondary`、hover `bg-hover`+`text-primary`；danger `status-error`/`text-white`、hover opacity .85。demo 字面量映射表（`#fff`→`--wb-text-white`；`#111`→`--wb-palette-black-90`（近似）；switch thumb 阴影 `rgba(0,0,0,.2)`→`--wb-palette-black-20`）只记录在本 design.md；css 头注释用文字描述（"demo 字面白/近黑映射为 token"），**不得**出现颜色字面量——守卫按原始行扫描、不剥注释。
- `Input`：`InputProps = { variant?: "search" } & ComponentPropsWithoutRef<"input">`。默认 `<input class="ui-input" {...rest}>`（demo:606-608：高 32/padding 0 12/radius 8/`border-input`/`color-bg-input`/13px；focus `brand-primary`；placeholder `text-tertiary`；width 100%）。`variant="search"`：`<div class="ui-input ui-input--search"><Icon name="search" size={14} /><input type="search" class="ui-input-search-field" {...rest} /></div>`（demo:609-612：容器 flex gap 6 padding 0 10 width 240；内层 input 无边框透明）。焦点环归容器：`.ui-input-search-field:focus-visible { outline: none }`，`.ui-input--search:has(.ui-input-search-field:focus-visible) { outline: 2px solid var(--wb-brand-primary); outline-offset: 2px; border-radius: 8px }`（review round 1：内层字段方环越出圆角容器）。可访问名由调用方经 `aria-label`/`placeholder` 提供。
