Governing invariant: one runtime owns at most one live child generation and its token; a turn settles exactly once without dropping pre-terminal frames, and no retired generation can affect its successor.

## Decisions
- Reuse OmpProcess rather than duplicate protocol or wrap an upstream runtime. Inject low-level SpawnImpl for real child tests, not a mocked system under test. Clock owns idle/escalation timers; transport handshake deadline remains transport-owned.
- OmpProcess retains real native kill forwarding/results and records only a successfully sent SIGKILL for its one child. Its startup-failure cleanup does not automatically repeat that hard-kill request; prior TERM and failed SIGKILL still permit startup termination. Runtime never monkeypatches the native ChildProcess kill method, and a successful signal request never substitutes for observed native death.
- Token port structurally follows #90: issue(sessionId):string and revoke(sessionId):void. Runtime requests a fresh token per process generation; crypto implementation remains #90. Do not import sessions/tokens or model-proxy. Revoke once on native exit or failed acquisition/startup without a live child; never retire a newer token from an old callback.
- Construction does not spawn or issue a token. Constructor accepts the caller's persisted resumePath as initial last-known-good sessionFile; omitted/null means cold. First prompt uses that exact path if present, including in a newly reconstructed runtime. Later turns reuse the child. Successful handshake updates sessionFile; failed handshake must not clear or replace the prior persisted/successful path. A never-successful startup with no persisted path retries cold.
- Bind listeners before starting/writing. A turn observes frames even when events precede ACK. ACK alone is not completion; agent_end is terminal only when isTerminal !== false. Matching prompt response data.agentInvoked=false or prompt_result agentInvoked=false completes a local-only prompt. Matching later success:false response fails that prompt, even after ACK. Unrelated ids cannot settle the active turn. Raw error/terminal frames remain observable; business status mapping belongs #83/#100.
- One active prompt; reject overlap rather than silently queue. A consumer abandoning its iterator must not leave a falsely idle/reusable active agent: reclaim that generation. Expose sanitized transport/startup/exit failures to the iterator; do not log raw payloads or credentials. Protocol errors fail/reclaim an active turn instead of silently committing an incomplete result.
- Idle resets on every child frame and each accepted new prompt, including during a turn. Idle expiry retires that generation; a later prompt waits for reclamation then restarts. Public shutdown is idempotent and permanently closes this runtime to new prompts; shutdown-before-prompt allocates nothing.
- Shutdown closes stdin immediately, sends TERM only if still alive after 5000ms, then KILL only if still alive after another 3000ms. Early native exit cancels signal escalation; do not signal a dead child or synthesize an exit. SIGKILL delivery is followed by observed native exit, not assumed process death. OS kill/reap responsiveness is an explicit platform assumption.
- Native exit revokes the credential immediately; logical exit drains complete buffered frames before deciding whether the turn was interrupted. A dead child with held-open stdout gets bounded drain cleanup using the same 8s shutdown budget, then streams are destroyed and any unfinished turn fails with the original exit. Never wait indefinitely on stdio to revoke a token or complete shutdown.
- New prompt during retirement waits for old child reclamation; shutdown racing directory preparation/startup must still reclaim any eventual child. Generation identity fences frames, timers, exit callbacks and token revocation after replacement.

## Risks / Trade-offs
The native/logical split avoids #95 buffered-frame loss but requires explicit drain ownership. Test held-pipe retirement and delayed old callbacks rather than equating native exit with output EOF.
Async iterable cancellation and shutdown may terminate an active turn; failure is explicit, never a fabricated successful terminal frame. Full mapper/store behavior belongs #100.
Critical verification covers declared failure classes with semantic counterexamples and independent parent smoke; no claim of arbitrary process-tree containment or same-uid isolation (ADR0010/S1a).
Migration/rollback: new unused module until #100; revert this slice, no data migration. No unresolved product decision; implementation may choose small internal types without changing these external invariants.
