- hook：`composer-options.ts` 导出 `useComposerOptions(client: Pick<ApiClient, "getComposerOptions">, requestedSessionId: string | null): ComposerOptions | null`，约 40 行。state 为 `{client, options}`，在途记录为 ref `{client, status: "pending" | "done" | "failed"}`。effect 依赖 `[client, requestedSessionId]`：ref 属于本 client 且不是 `failed` 就跳过，否则换一条新记录并发请求；落定时 ref 已不是自己的记录就丢弃。返回 `state.client === client ? state.options : null`。
