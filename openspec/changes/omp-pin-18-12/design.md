## Goals / Non-Goals

**Goals:**

## Risks / Trade-offs

- [`rpc-ui` 的 `hasUI=true` 牵动 sdk.ts 约 8 处，读码只核了六处] → 组 2 开工核对实跑三档各一回合（含工具调用与一次 `get_state`），差异写进 PR；非审批 UI 请求照旧 cancel，所以任何新冒出的确认都以取消收场而不是挂起；`ask` 是已知例外（cancel 即中止回合），由 overlay `ask.enabled: false` 关掉并以真实 omp 场景钉住；真实 omp 场景另断言 bash 回合的上游请求数在 `rpc-ui` 与 `rpc` 下相同。
- [prelude 盲卡自动放行等于把「每次浏览器宿主调用再问一次」关掉] → 真正执行的代码在 eval 卡上已经被用户批准（或档位自动放行）；盲卡零信息；`session.browser` 从 statusEvents 逐次留痕。`yolo` 档与 18.0.10 一样不因档位出卡（工具自带的强制提示另计）。
- [eval 审批卡只显示前 2000 字符的代码] → 18.0.10 同值，既有行为；范围外登记。
- [`statusEvents` 有上限、溢出从头丢弃] → `statusEventsElided` 为正时写一条登记条数的审计，不伪造条目。
- [截图目录比对会把同一步骤里经 `tab.run` 写进 `screenshots/` 的任意文件算作截图] → 仍在空间内、仍是本回合写出的文件，进文件变更卡无害；写进规格。
- [`.git` 空目录出现在用户工作空间] → 文件页与 `/tree` 不过滤点开头条目，用户会在每个空间看到一个空的 `.git` 目录（Context；不改前端，Non-Goals；是否加验收行待 owner）；用户 `git init` 直接填入；omp 用户能删它，下一次 spawn 重建，SYSTEM.md 只在启动时读；omp 把 cwd 当仓库根而 git 命令报 `not a git repository`，组 3 在 18.0.10、组 6 在 18.12.3 实跑确认无报错帧、无 stderr 噪音。
