## Goals / Non-Goals
Generate exactly the declared provider config and usable address from actual TCP AddressInfo. Preserve model IDs as strings even with YAML-significant characters; no value can inject another provider/property. Two equal calls produce identical file bytes; changed options replace stale managed content.
No server startup invocation, token issuance, HTTP proxy implementation, subprocess launch, file sandbox ownership redesign, general YAML framework, hot reload/concurrent writer protocol, upstream env reads or key expansion. Directory is caller-selected trusted parent-owned state, not a user path API.
## Decisions
Use existing Node fs/promises/path/net types; no new runtime dependency. Existing root yaml package may parse in tests. Block YAML with scalar quoting is preferred over whole-document JSON because fake-omp intentionally supports only the managed block subset; do not change fake parser to accommodate an alternative generator.
Address input is actual TCP AddressInfo: wildcard0.0.0.0→127.0.0.1, wildcard::→::1; retain explicit IPv4/IPv6, wrap IPv6 once, use actual port and /v1 suffix. No environment HOST/PORT guessing, validation policy for impossible AddressInfo, or hostname resolution needed.
writeManagedModelsYml creates agentDir if absent, writes only models.yml, and overwrites stale contents. JSON-string quoting is valid YAML scalar escaping; id and name use the provided modelId; apiKey is literal WORKBUDDY_MODEL_TOKEN. Fixed api openai-completions/contextWindow128000/maxTokens8192. Do not write authHeader, read process.env, or copy upstream/token values into content. Existing filesystem failures reject; no catch-and-pretend-success. Idempotence concerns content bytes, not mtime/no-write optimization. Startup caller awaits before spawning, so concurrent-reader atomic replacement is not a new requirement here.
## Governing invariant / siblings
Generated child-readable config contains one local provider with env-name credential indirection and exact supplied model identity, never parent service credentials. Preserve proxy/index.ts; fake-omp block reader; OmpProcess child env whitelist; future server.ts startup order and model ID config. No duplicate implementation/re-export shim.
