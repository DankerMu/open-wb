## Decisions
1. Registration is registerWorkspaces(app,{store:WorkspaceStore,sandbox:ReturnType<typeof createSandbox>,audit:bound canonical emit object}). Composition constructs one store from db+sandboxRoot, one bound audit on that same db, then facade from store.rootOf; inject all three. No route reads process.env, creates another store, copies SQL, or exports standalone rootOf alias. index is the module entry and rest owns routes; avoid unused forwarding exports. #128 consumes this exact seam.
2. Reuse createApp's cookie/auth/guard/error handler. Register module before ready/listen like accounts. Every exact route sets no-store in onRequest, before guard/preParsing/parser; preserve all 401/400/403/404/409/413/415/500 envelopes. No global-header/auth/parser-policy change. POST bodyLimit16*1024, only application/json (allow charset); reject nonJSON even text/plain parsed by Fastify. Body shape plain object only, exact {name,dir?} or {path}; required strings/optional dir string, no unknown authority fields. No schema coercion or UTF16 maxlength duplication: domain name/dir stays in store. Repeated path query is400; tree absent path defaults empty, file requires string path. Ignore unrelated query fields, never wire identity.
3. Collection GET returns {workspaces:store.list(principal.id)} and POST201 returns store.create(principal,body). Only three routes have :id: tree/dirs/file. Foreign/missing typed requests get404 with no audit/FS changes, including unsafe path strings; malformed bodies/query retain explicit400/parser precedence, unauthenticated401 precedes handler. Collection isolation is list owner filter and create caller ownership, not an invented collection/:id route.
4. Safe existence ordering: for scoped routes establish owner root using store.rootOf before metadata; foreign/missing404. A valid owned root that is absent/non-directory returns404 without fake sandbox rejection. Do not create roots on reads. Existing unsafe persisted root failures remain generic500 per store contract. For existing ordinary root pass original decoded rel string unchanged to sandbox.resolve (op=list/mkdir/read); no decode twice, trim/normalization or reason-string parsing. Facade still owns actual denial/audit. This explicit owner-root preflight may repeat the facade lookup; do not change public facade semantics just to avoid one query.
5. Canonical resolve correction: ENOTDIR below already-inspected ordinary non-symlink component is structural absence, like a missing descendant, not escape. Allow resolution to continue so later '..'/NUL/absolute/symlink rules still reject. Do not authorize EACCES or arbitrary metadata errors. Update the old ENOTDIR test to correct contract with semanticRED first and preserve real unexpected-error rejection coverage. No alternate resolver/path policy in routes. Main source-preserving native probe is evidence; new HTTP regression must fail old resolver403 and pass404, with no rejection audit.
6. Tree uses listOneLevel only after ordinary-directory metadata; missing/non-directory404. Return raw decoded {path,entries}, production sorting/mtime/size untouched; symlinks/specials omitted. Filesystem ENOENT/ENOTDIR maps404 at metadata seam, other errors generic500 via canonical handler without nativepath disclosure.
7. Dirs: authorize original path opmkdir first; require immediate parent ordinary existing dir (404 otherwise), existing target409 (unsafe symlink already403); no recursive parent creation. Then canonical sandbox.ensureSharedDir(target), then bound audit.emit({kind:'dir.create',actorId,workspaceId,title:'新建目录 '+rawPath,detail:{path:rawPath}}), then201{path:rawPath}. Root/empty/dot/traversal invalidity stays resolver403+audit, not silently400. Duplicate409 must not emit/create. Do not add transactional filesystem compensation absent parent requirement: if ensure or audit fails, generic500/no false201; an already-created directory may remain and is explicitly tested/disclosed. Stable FS assumption excludes external target replacement/races.

Preview: authorize original path, ordinary-file metadata first so missing/directories/FIFO return404 even unsupported extension. extname stripped dot -> classifier; consume production headers and limit directly; unsupported415/oversize413 before openPreviewStream. reply.send(nativeStream) uses Fastify's own backpressure/close/error ownership, no redundant wrapper/listeners. Workspace store failure retains its exact rollback/compensation policy; route must not catch/recover caller transaction or report success.
