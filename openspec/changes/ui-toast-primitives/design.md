- `toast.tsx`：
  - `type ToastType = "success" | "error" | "info"`；`type ToastRecord = { id: number; type: ToastType; message: string }`；`const MAX_TOASTS = 3`、`const TOAST_DURATION_MS = 2400`。
  - `ToastContext = createContext<{ show(input: { type: ToastType; message: string }): void } | null>(null)`。
  - `export function ToastProvider({ children }: { children: ReactNode })`：单一状态 `const [state, setState] = useState<{ toasts: ToastRecord[]; epoch: number }>({ toasts: [], epoch: 0 })`；`const nextId = useRef(0)`；`show = useCallback(({type,message}) => setState(prev => ({ ...prev, toasts: [...prev.toasts, {id: nextId.current++, type, message}].slice(-MAX_TOASTS) })), [])`（超过 3 条丢最旧）；`dismiss(id) = setState(prev => { const toasts = prev.toasts.filter(t => t.id !== id); return { toasts, epoch: toasts.length === 0 && prev.toasts.length > 0 ? prev.epoch + 1 : prev.epoch }; })`——队列从非空变空时 `epoch` +1。渲染：`<ToastContext.Provider value={{show}}>{children}<ToastPrimitive.Provider key={state.epoch} duration={TOAST_DURATION_MS} label="通知">{state.toasts.map(t => <ToastPrimitive.Root className={`ui-toast ui-toast--${t.type}`} key={t.id} onOpenChange={open => { if (!open) dismiss(t.id); }} open type="background"><Icon name={ICONS[t.type]} size={16} /><ToastPrimitive.Description className="ui-toast-message">{t.message}</ToastPrimitive.Description></ToastPrimitive.Root>)}<ToastPrimitive.Viewport className="ui-toast-viewport" label="通知" /></ToastPrimitive.Provider></ToastContext.Provider>`。**`{children}` 在 Radix Provider 之外**（`useToast` 只依赖本仓 `ToastContext`，应用树不需要 Radix Toast context），故 `key={epoch}` 只重挂 Radix Provider + Viewport，不重挂应用。**为什么要 epoch**（Radix 1.2.23 上游行为，`react-toast/dist/index.mjs:37,94-132,355`）：`isClosePausedRef` 由 Radix Provider 持有，只有 Viewport 在 `hasToasts` 时挂的 `pointerleave`/`focusout` 监听会把它清回 false；悬停或聚焦中用 Escape/滑动关掉最后一条 toast 后监听随之卸载，ref 永远停在 true，之后新 toast 挂载时 `open && !isClosePausedRef.current` 不成立、永不自动关闭。队列清空即重挂 Provider 让 ref 归零；同时旧 `<ol>` 卸载使残留焦点回到 body。`ICONS = { success: "circle-check", error: "triangle-alert", info: "info" } as const`。`value` 用 `useMemo` 固定引用。Radix 提供：`duration` 到期 `onOpenChange(false)`（`window.setTimeout`，hover/focus 暂停、离开恢复）、Escape 关闭、滑动关闭、`type="background"` 的隐藏播报区 `role="status" aria-live="polite"`（挂载后约 1s 卸载）、Viewport `role="region" aria-label="通知"` + `<ol>`、F8 聚焦。本仓不写任何定时器。
