# 认证做 provider 接缝，OIDC 为首个适配器

> **已被 ADR-0018 取代**（[0018-local-accounts-only.md](0018-local-accounts-only.md)，owner 2026-11-17）：部署环境没有统一身份系统，本地账号是唯一身份来源，OIDC 从路线图上去掉。下文保留为当时的记录。

内网统一身份对接 OIDC；auth 模块做成 provider 接缝，OIDC 与开发态登录桩是两个适配器（两个适配器
= 真接缝），将来 LDAP/信任头可平移接入。身份字段由 IdP 下发、应用侧不可改；管理员只管应用侧属性
（角色/配额/启停）。项目组默认自建；若 IdP 带组声明则改为同步（见架构文档开放问题）。
